💻 私たちの開発スタイル at Fujitec
私たちは、開発の効率と品質を両立させるために、以下のルールを標準としています。

ブランチ運用

新機能開発: 

feature/<id> 

リリース準備: 

release/<ver> 

緊急修正: 

hotfix/<id> 


mainブランチへの直接Pushは禁止し、必ず2名以上のレビューを必須としています 。


Pull Request (PR) のルール

PRを作成する際は、テンプレートに沿って以下の4項目を必ず記載します 。

背景

変更点

動作確認 (スクリーンショット含む)

リスク・対応策

テンプレートが未記入のPRはマージできません 。

必須ファイル

各リポジトリには、開発の指針となる

README.md, CONTRIBUTING.md, CODEOWNERSを設置します 。
